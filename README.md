# GitHub Repository Analyzer

An AI-powered web application that analyzes GitHub repositories and provides structured insights about their **code quality, project structure, documentation, and development activity**.

It also includes a **Roast Mode 😈** that presents the same factual analysis with a sarcastic and humorous tone.

## Features

* 🔍 Analyze any public GitHub repository
* 🤖 AI-powered repository analysis using Ollama Cloud
* 📊 Overall repository score
* 📈 Code Quality, Structure, Documentation & Activity scores
* 💪 Strengths and weaknesses
* 💡 Practical recommendations
* 😈 Roast Mode for a more entertaining analysis
* 📁 Repository structure analysis
* 📝 README/documentation analysis
* 📊 Language distribution
* 👥 Contributor information
* ⚡ No database required

### Professional Mode

Provides an objective analysis with:

* Repository strengths

* Documentation evaluation
* Activity analysis
* Practical recommendations

### Roast Mode 😈

Uses the same underlying repository data and scores but presents the findings in a sarcastic and humorous way.

The AI is instructed not to invent technical problems or make personal attacks.

## Running Locally

### 1. Clone the repository

```bash
git clone https://github.com/your-username/github-repository-analyzer.git
cd github-repository-analyzer
```

### 2. Install frontend dependencies

```bash
cd client
npm install
```

### 3. Install backend dependencies

```bash
cd ../server
npm install
```

### 4. Configure environment variables

Create a `.env` file inside the `server` directory:

```env
GITHUB_TOKEN=your_github_token
OLLAMA_API_KEY=your_ollama_api_key
FRONTEND_URL=http://localhost:5173
```

Create a `.env` file inside the `client` directory:

```env
VITE_API_URL=http://localhost:5000
```

### 5. Start the backend

```bash
cd server
node server.js
```

### 6. Start the frontend

```bash
cd client
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## Scoring

The repository receives four component scores:

| Category      | Weight |
| ------------- | -----: |
| Code Quality  |    30% |
| Structure     |    25% |
| Documentation |    20% |
| Activity      |    25% |

The final score is calculated from these weighted components rather than being independently generated by the AI.

> Note: Code Quality is evaluated using repository-level signals rather than a line-by-line source-code review.

## Deployment

The application is deployed using:

* **Frontend:** Vercel
* **Backend:** Render
* **AI:** Ollama Cloud

The frontend communicates with the deployed Express API through an environment variable:

```env
VITE_API_URL=https://your-backend-url
```

## Disclaimer

The analyzer evaluates repositories using publicly available GitHub metadata, repository structure, documentation, and activity signals.

It should be treated as an **AI-assisted repository review**, not a replacement for a detailed human code review.
